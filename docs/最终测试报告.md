## 五、真实缺陷清单

> 该系统已在企业内部投入使用，主流程稳定，本次测试发现的问题集中在边缘场景。

### Bug-1：直接访问域名返回 502（P1）

- **现象**：在 Chrome / Safari 直接输入 `app.cetconline.com` 打开商城，显示 **502 Bad Gateway**；
- **正确入口**：必须通过微信扫码进入；
- **推断**：正式入口网关配置只放行微信容器内的访问，或 nginx 路由对裸域名访问未配置；
- **影响**：外部用户 / 直接访问 URL 的用户无法进入商城；
- **建议**：在 nginx / 网关上配置裸域名的兜底跳转，或明确告知用户正确入口。

### Bug-2：从分享链接进入订单页后无法返回首页（P2）

- **现象**：购买完成后将订单页分享给其他用户，对方能打开订单页；但退出后再次进入同一个 URL，**只能停留在订单页，左上角箭头直接退出 H5，无法返回首页**；
- **复现**：分享订单链接 → 新用户打开 → 看到订单页 → 点左上角 → 直接退出，无回首页入口；
- **推断**：H5 路由栈设计问题，深链进入时没有维护首页回退；
- **影响**：用户从订单链接进入后被困在订单页；
- **建议**：在订单页左上角加"返回商城"入口，或深链进入时在路由栈前置首页。

### Bug-3：iPad 页面显示不全 / 登录按钮缺失（P2）

- **现象**：用 iPad 打开 H5，页面布局显示不全；旋转屏幕后**登录按钮仍然不显示**，无法完成登录；
- **推断**：H5 仅针对手机视口（375~414 宽度）做了适配，平板宽度未做响应式处理；
- **影响**：iPad 用户无法正常使用；
- **建议**：增加平板视口适配，或在 iPad 视口下给出"请使用手机打开"的提示。

## 六、接口测试

### 6.1 方法

- 用 Chrome DevTools / Charles 抓取核心业务接口；
- 在 Postman 中重放**只读接口**（写接口不重放，避免污染生产数据）；
- 每个接口写 6 条 Tests 断言。

### 6.2 接口清单

| Service 名 | 业务含义 |
|---|---|
| `WEBAPI_FLSC_getCartList` | 获取购物车列表 |
| `WEBAPI_FLSC_SearchShopDetailInfo` | 商品详情 |
| `WEBAPI_FLSC_QueryOrderList` | 订单列表 |
| `WEBAPI_FLSC_OrderDetail` | 订单详情 |

### 6.3 断言策略（每个接口 6 条）

1. HTTP 状态码 = 200
2. 响应时间 < 1500ms
3. 响应是合法 JSON
4. 业务 `status` 字段 = "200"
5. 响应包含 `result` 字段
6. `result` 非空

### 6.4 结果

- 集合名：**电科商城H5-只读接口**
- 总断言数：4 接口 × 6 = **24 条**
- 通过：**24/24**，0 错误
- 平均响应时间：**491ms**
- 备注：业务响应体为 hex 加密，只能校验外层结构，无法断言业务字段值（已在报告中记录此限制）。

- Python 3.11 + Selenium 4 + pytest + Allure

- 登录态方案：**Cookie 注入**绕开图形+短信验证码

### 7.2 用例清单（6 条）

| 用例 | 作用 | 结果 |
|---|---|---|
| test_no_redirect_to_login | 验证 Cookie 注入后未跳登录页 | PASSED |
| test_page_loaded | 验证首页加载、文本 > 50 字符 | PASSED |
| test_homepage_has_content | 验证首页命中商城关键词 | PASSED |
| test_search_box_exists | 验证首页能定位到搜索框 | PASSED |
| test_search_keyword_returns_results | 输入"大米"搜索并验证结果 | SKIPPED |
| test_cart_page_loads | 直接访问购物车 URL | SKIPPED |

### 7.3 结果

- **4 passed, 2 skipped, 0 failed**
- 总耗时：127.93s
- 截图证据：`screenshots/01_首页.png` ~ `05_购物车页.png`
- 终端证据：`reports/UI自动化测试结果.txt`

### 7.4 主动 skip 的原因

1. **搜索用例 skip**：首页搜索框是"假 div"，点击会跳转 `/commoditySearch`，真正的输入框在新页面；直接对隐藏 input 发 `send_keys` 无效。需要先点击跳页再定位，已记录为后续优化项。
2. **购物车用例 skip**：购物车依赖 JS 侧 localStorage token，HTTP Cookie 注入覆盖不到。黑盒条件下不强行覆盖，主动识别风险并跳过。
