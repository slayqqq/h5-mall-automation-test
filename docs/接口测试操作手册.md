# 电科商城 H5 接口测试操作手册（Charles + Postman）

> 目标：亲手抓到 3~5 个核心只读接口，在 Postman 里重放并自动校验，对比页面展示与接口字段，发现 1~2 个前后端数据不一致问题。



***

## 第 0 步：安全红线（先读，再动手）



| 接口类型               | 例子                                       | 能不能在 Postman 重放    |
| ------------------ | ---------------------------------------- | ------------------ |
| **只读 GET**         | 商品列表、商品详情、购物车查询、订单列表                     | ✅ 随便重放，无副作用        |
| **只读 POST**（语义是查询） | `POST /api/queryCart`、`POST /api/search` | ⚠️ 可以重放，但先确认它不写库   |
| **写接口**            | 加购、下单、改地址、删除                             | ⚠️ 只构造异常参数测试，不真正提交 |
| **支付接口**           | `/pay/create`、`/pay/callback`            | ❌ 一律不碰             |

**判断方法**：在 Charles 里看这个请求真实发出时页面做了什么 —— 点 "加入购物车" 发出的就是写接口；进商品详情页自动发出的就是只读接口。



***

## 第 1 步：装 Charles 并配置 HTTPS 抓包

### 1.1 下载安装



* 官网 [https://www.charlesproxy.com/download/](https://www.charlesproxy.com/download/)  下载 Windows 版（.msi），一路下一步。

* 打开 Charles，首次会弹窗问 "是否允许 Charles 监听网络"，选允许。

### 1.2 安装并信任根证书（关键，不装只能看到 URL 看不到内容）



1. Charles 顶部菜单：`Help → SSL Proxying → Install Charles Root Certificate`；

2. 弹窗点 "安装证书" → 选 "本地计算机" → 下一步 → 选 "将所有的证书都放入下列存储" → 浏览选 **"受信任的根证书颁发机构"** → 完成；

3. 看到 "导入成功"。

### 1.3 开启 SSL 代理



1. 菜单：`Proxy → SSL Proxying Settings`；

2. 勾选 **Enable SSL Proxying**；

3. 点 Add，Host 填 `*`，Port 填 `443`（表示抓所有 HTTPS）；

4. 确定。

### 1.4 看本机 IP（手机代理要用）



* PowerShell 跑：`ipconfig`，找 "无线局域网适配器 WLAN" 里的 **IPv4 地址**，例如 `192.168.1.100`，记下来。



***

## 第 2 步：手机配代理并抓 H5

### 2.1 手机连同一 WiFi



* 手机 WiFi 必须和电脑在**同一个路由器**下。

### 2.2 手机设手动代理

**iPhone**：



1. 设置 → 无线局域网 → 点当前 WiFi 右边的 ⓘ；

2. 拉到底 "配置代理" → 选**手动**；

3. 服务器填电脑 IP（如 `192.168.1.100`），端口填 `8888`（Charles 默认端口）；

4. 存储。

**Android**：



1. 长按当前 WiFi → 修改网络 → 高级选项 → 代理 → 手动；

2. 主机名填电脑 IP，端口 `8888`。

### 2.3 手机装 Charles 证书



1. 手机浏览器（Safari/Chrome，**不是微信**）打开：`chls.pro/ssl`；

2. 会下载一个 `.pem` 证书；

3. **iPhone**：

* 设置 → 通用 → VPN 与设备管理 → 点刚下载的证书 → 安装；

* 再去 设置 → 通用 → 关于本机 → 拉到底 **证书信任设置** → 把 Charles 证书开关打开。

1. **Android**：设置 → 安全 → 从存储安装证书 → 选刚下载的 .pem。

### 2.4 开始抓包



1. 打开 Charles，手机上第一次联网时会弹 "是否允许 XXX 设备连接"，点 **Allow**；

2. 打开微信 / 手机浏览器，进商城 H5；

3. 回到 Charles，左侧 **Sequence（序列）** 视图，能看到所有请求。

### 2.5 过滤只看商城请求



* Charles 底部有个 "Filter" 输入框，把商城域名输进去（比如 `cetec-mall` 或你们公司域名关键词）；

* 只保留相关请求，其它广告 / 统计请求全部隐藏。



***

## 第 3 步：走一遍商城，把 5 个核心接口记下来

依次在 H5 上做这些动作，Charles 里找对应请求，填到下面这张表：



| 动作          | 预期接口（示例名）                           | 方法       | URL | 关键参数      | 是否只读   | 记录  |
| ----------- | ----------------------------------- | -------- | --- | --------- | ------ | --- |
| 输入手机号点获取验证码 | `/api/sms/send`                     | POST     |     | 手机号       | 写（不重放） | 填实际 |
| 登录          | `/api/login`                        | POST     |     | 手机号 + 验证码 | 写（不重放） | 填实际 |
| 进首页加载商品     | `/api/banner`、`/api/home/recommend` | GET      |     | 无         | ✅ 只读   | 填实际 |
| 点搜索         | `/api/search?keyword=xx`            | GET/POST |     | keyword   | ✅ 只读   | 填实际 |
| 进商品详情       | `/api/product/{id}`                 | GET      |     | 商品 id     | ✅ 只读   | 填实际 |
| 进购物车        | `/api/cart`                         | GET      |     | 无         | ✅ 只读   | 填实际 |
| 进订单列表       | `/api/orders?status=x`              | GET      |     | 状态        | ✅ 只读   | 填实际 |

**怎么从 Charles 拿请求信息**：



* 选中一个请求 → 右侧 **Contents** 标签 → **Request** 子标签看请求头 / 参数；

* **Response** 子标签看返回的 JSON；

* 右键请求 → **Copy cURL Request**，可以直接粘到 Postman。

**关键：登录成功后 Response 里会返回一个 token**（通常是 `data.token` 或 `data.accessToken`），复制存好，后面所有请求都要带它。



***

## 第 4 步：Postman 重放只读接口

### 4.1 建环境变量



1. Postman 右上角眼睛图标 / Environments → New Environment；

2. 建两个变量：

* `base_url` = 你商城的域名（如 `https://xxx.com`）

* `token` = 刚才复制的 token

1. 右上角环境选择器切到这个环境。

### 4.2 建集合



* New Collection 名字：`电科商城H5-只读接口`；

* 每个只读接口建一个 Request：


  * URL 用变量：`{{base_url}}/api/product/123`

  * Headers 加：`Authorization: Bearer {{token}}`（具体头名以 Charles 里看到的为准，可能是 `token`、`X-Token`、`Cookie`）

### 4.3 写 Tests 自动校验（核心，面试能讲）

每个请求的 **Tests** 标签里贴这段（按需改字段名）：



```
// 1. 状态码
pm.test("状态码=200", function () {
    pm.response.to.have.status(200);
});

// 2. 响应时间 < 1.5 秒
pm.test("响应时间<1500ms", function () {
    pm.expect(pm.response.responseTime).to.be.below(1500);
});

// 3. 业务 code = 0（具体 code 以你们接口为准，常见是 0 或 200）
pm.test("业务code=0", function () {
    var json = pm.response.json();
    pm.expect(json.code).to.eql(0);
});

// 4. 商品详情必须有 name/price/stock
pm.test("商品字段完整", function () {
    var d = pm.response.json().data;
    pm.expect(d).to.have.property("name");
    pm.expect(d).to.have.property("price");
    pm.expect(d).to.have.property("stock");
});

// 5. 价格必须 > 0
pm.test("价格为正数", function () {
    var d = pm.response.json().data;
    pm.expect(d.price).to.be.above(0);
});
```

点 **Send**，下方 "Test Results" 全绿 = 通过。

### 4.4 跑一遍集合（一键回归）



* Collection 上点右键 → **Run collection** → 选环境 → Start Run；

* 出一份 Html 报告，可以截图当简历素材。



***

## 第 5 步：找 "前后端数据不一致"（简历金句的来源）

这一步最值钱，是你简历里 "发现前后端数据不一致问题" 那句话的证据：



1. **商品价格**：H5 详情页显示 ¥99.00 → Charles 里 `/api/product/123` 返回 `price: 9900`（分）还是 `99.00`（元）？单位不一致 = bug；

2. **商品数量**：购物车页显示 "共 3 件" → `/api/cart` 返回的 `totalQuantity` 是不是 3？

3. **库存**：详情页显示 "库存 5 件" → 接口 `stock` 字段是不是 5？

4. **刷新对比**：同一接口连续发两次，字段值变不变？（列表排序两次结果不一样 = bug）；

5. **弱网**：Charles 顶部 `Proxy → Throttling Settings` 限速到 "56K modem"，重新进页面，看接口超时有没有友好提示。

把发现的每个不一致，按 "缺陷记录模板.csv" 格式记下来：截图 + 接口返回 + 页面显示对比。

## 常见坑



| 现象                          | 原因                   | 解决                    |
| --------------------------- | -------------------- | --------------------- |
| Charles 里接口全是 `unknown` 或乱码 | 证书没装好                | 重做 1.2 和 2.3          |
| 手机联网但 Charles 没数据           | 代理没设对 / 电脑防火墙拦了      | 关电脑防火墙试试              |
| 微信里抓不到请求                    | 微信某些请求不走系统代理         | 改用手机 Chrome 打开同一 H5 测 |
| Postman 报 401/403           | token 过期或 header 名不对 | 重新抓一次登录，复制最新 token    |
| 接口返回 code≠0 但页面正常           | 你们 code 定义不是 0       | 按真实返回改 Tests 脚本       |
